Elyne Red Unifiée est le moteur d'exercices adversariaux fourni avec EAS Défense. Ses actions, lorsqu'une campagne est autorisée et exécutée, produisent des effets réels dans le périmètre prévu. Le moteur distingue le **résultat technique d'un tir** du **verdict de défense** attribué après corrélation avec EAS et l'état de la cible.

La même interface orchestre des scénarios **MITRE ATLAS** visant les interfaces d'agents, dont la spécialité **Red Agentic**, et des techniques **MITRE ATT&CK** sur un hôte de laboratoire. Un manifeste fixe les cibles, transports, durées et capacités ; l'exécution dispose d'un arrêt et d'une procédure de restauration. Le catalogue présente Red Unifiée au statut **Évaluation**.
