Elyne Red Unified is the adversarial exercise engine supplied with EAS Defense. Once a campaign is authorized and executed, its actions have real effects within the approved scope. The engine separates the **technical result of an action** from the **defense verdict**, which requires correlation with EAS and the target's observed state.

One interface orchestrates **MITRE ATLAS** scenarios against agent interfaces, including the **Red Agentic** specialty, and **MITRE ATT&CK** techniques on a laboratory host. An engagement manifest fixes targets, transports, duration, and capabilities; execution includes a stop mechanism and restoration procedure. The catalogue lists Red Unified as **Evaluation**.
